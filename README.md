# Витрина: сайт vitrina-web.com

Одностраничный сайт студии «Витрина»: «сделаю сайт или Telegram-бота для вашего бизнеса или научу делать так же». Статический HTML, без сборки и серверной части. Заявки принимает Telegram-бот (см. `C:\Users\Karolina\Downloads\bots\vitrina-bot`).

## Как это устроено

```
 Клиент открывает vitrina-web.com        (GitHub Pages, этот репозиторий)
        │  нажимает «Заказать» или «Научите»
        ▼
 Бот @vitrina_web_bot в Telegram         (Cloudflare Worker)
        │  задаёт вопросы анкеты, ответы хранит в KV
        ▼
 Заявка приходит владелице в Telegram    («🆕 Новая заявка на работу» / «🎓 Новая заявка на обучение»)
```

Кнопки сайта ведут в бота с меткой: `?start=site` (заказать) и `?start=learn` (научить). Бот по метке сразу открывает нужную анкету.

## Что где лежит

| Файл или папка | Для чего |
|---|---|
| `index.html` | Главная страница: весь текст, стили и скрипты в одном файле. Есть RU и EN версии |
| `sajt-dlya-salona-krasoty/`, `sajt-dlya-rieltora/`, `sajt-dlya-fotografa/`, `seo-prodvizhenie-sajta/`, `voronka-prodazh/`, `ozhivit-foto-onlajn/` | SEO-страницы. Не править руками: они собираются скриптом |
| `_tools/make_pages.py` | Собирает SEO-страницы и обновляет `sitemap.xml`. Папка `_tools` на сайт не попадает по смыслу, это только инструмент |
| `assets/pages.css` | Стили SEO-страниц |
| `images/` | Картинки сайта, включая `og.jpg` (превью при отправке ссылки) |
| `work/`, `demo/` | Портфолио и демонстрационные сайты |
| `robots.txt`, `sitemap.xml` | Для поисковиков |
| `CNAME` | Привязка домена vitrina-web.com. Не удалять |

## Как обновить сайт

1. Поменять файл (обычно `index.html`).
2. Проверить локально: открыть `index.html` в браузере.
3. Выложить:
   ```
   git add -A
   git commit -m "Что изменилось"
   git push
   ```
4. GitHub Pages обновит сайт за 1–2 минуты. Браузеры кешируют страницу до 10 минут, поэтому обновить её нужно через Ctrl+F5.

## Как поменять SEO-страницы

1. Правим тексты в `_tools/make_pages.py`.
2. Запускаем `python _tools/make_pages.py` (дата обновления `TODAY` в начале скрипта).
3. Выкладываем как обычно через `git push`.

## Важно знать

- Сайт публикуется из ветки `main` репозитория `KeriMalina/vitrina-web`.
- Цена обучения на сайте не указана: «обсуждаются в боте».
- Сайт без автопроверок и автодеплоя: ошибки видны только после выкладки, поэтому смотрим страницу после каждого `git push`.
